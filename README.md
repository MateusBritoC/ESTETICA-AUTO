# Elite Auto Estetica

Landing page de estetica automotiva, desenvolvida com React, TypeScript, Vite e Tailwind CSS.

## Requisitos

- Node.js 18+
- npm

## Como rodar localmente

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev`: inicia o ambiente de desenvolvimento
- `npm run build`: gera build de producao
- `npm run preview`: sobe preview da build
- `npm run lint`: executa lint
- `npm run test`: executa testes

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
